## Alcance

La Actividad 4 integra y reflexiona sobre el sistema desarrollado en las actividades 1 a 3: preparación de microdatos de exportaciones, entrenamiento y selección del modelo `champion`, inferencia por lotes y API FastAPI, monitoreo de *drift* y pruebas automatizadas. El documento presenta las decisiones tomadas, las dificultades encontradas, los aprendizajes y el trabajo pendiente.

Esta actividad es un entregable documental; no incorpora nuevos desarrollos técnicos. Se documentan las **95 pruebas automatizadas aprobadas** y se aclara que **GitHub Actions no se implementó**, por tratarse de una opción no obligatoria de la guía.
